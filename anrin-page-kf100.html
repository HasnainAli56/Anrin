Reinforced edge channel KF-100

Gutter size

  • PRODUCT DESCRIPTION

    The ANRIN KF-100 edge protection channel is a technically advanced drainage system with an 8 mm thick edge protection profile made of KTL-coated cast iron. Suitable for all traffic loads from normal passenger cars to intensive truck or heavy-duty traffic, this channel system has all the key features of a universal linear drainage system with a nominal width of 100.
